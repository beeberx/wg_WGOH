# wgoh-nwes
GitHub repository for the ICES WGOH North West European Shelf region group. Overview of contents below. 

## Code
Folder with useful code

## DataCallSubmissions
Folder with data submissions in the defined boxes (see BoxDefs_NWES.csv)

## IROC_Timeseries
Folder with the relevant timeseries from the IROC Online Portal https://ocean.ices.dk/core/iroc

## Stations_and_Sections
Folder with standard sections and repeat stations within the NWES region
